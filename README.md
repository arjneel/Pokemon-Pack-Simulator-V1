# About

The Pokemon Pack Simulator is a project written for the purpose of experiencing the joy of opening Pokemon 
packs without paying actual money for them. Not only can you open packs though, it also keeps track of your money and best card so you can battle with your rarest 
card agaisnt a random opponent and sell your rarest card for its actual real world value in the shop. The pokemon pack we used is the most recently released pack called 
"Pitch Black," it features 120 different cards and the simulator generates the packs based on real world probabilities for cards. In addition, you are able to save your progress through signing up
in the app as a custom username which saves to a file, resign in to save new info, and login to load the info saved.

# Prerequisites

1. Python installed

2. A coding app installed (VSCode/Pycharm)

3. 'pip install Flask pandas' in the app terminal to download flask and pandas


# Installation

1. Download the files folder

2. Upload folder to your code editor

3. Create the virtual environment (venv) folder with requirements.txt

4. Run with 'flask --app final-project.py run'

# Features

Opening Pitch Black Pokemon packs

Selling cards

Battling an opponent

Saving your data with a log in.
